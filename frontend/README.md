# Frontend de AI Trading

Interfaz React/Vite conectada a Firebase Authentication y a la API de señales.

La guía completa de configuración está en `../README.md`. Antes de iniciar,
copie `.env.example` a `.env.local` y agregue la configuración de su
aplicación web Firebase.

Comandos:

```text
npm.cmd install
npm.cmd run dev
npm.cmd run lint
npm.cmd run build
```
